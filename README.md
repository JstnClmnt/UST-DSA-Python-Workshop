# Customer Churn Predictor

> AI-powered customer churn prediction app built for a 90-minute Python workshop at the University of Santo Tomas, Manila.

This repository demonstrates an end-to-end ML pipeline — from exploratory data analysis in Jupyter to a production Streamlit app with Claude AI integration for generating business recommendations.

## What This Project Does

Predicts which e-commerce customers are likely to churn using a [Kaggle dataset](https://www.kaggle.com/datasets/samuelsemaya/e-commerce-customer-churn) of 3,941 customers with 10 features. A Streamlit app lets you look up individual customers, view their churn risk score from a trained Random Forest model, and get AI-generated retention recommendations via Claude.

**Two main views:**

- **Customer Lookup** — Select a customer, view their profile metrics, churn risk percentage (color-coded), order history, and an AI-generated recommendation
- **City Analytics** — Compare churn rates, revenue, and satisfaction across 24 Philippine cities with AI-generated insights

## Dataset

[E-Commerce Customer Churn](https://www.kaggle.com/datasets/samuelsemaya/e-commerce-customer-churn) from Kaggle — 3,941 customers with 10 features and a binary churn label (~17% churn rate). Customer names and Philippine cities are synthetic, generated by `scripts/build_churn_db.py`.

## ML Pipeline

The notebook (`notebooks/01_churn_model.ipynb`) trains and compares three models using `GridSearchCV` with 5-fold cross-validation:

| Model | Accuracy | F1 | F2 | Recall |
|-------|----------|------|------|--------|
| **Random Forest** | 93.5% | 0.79 | 0.74 | 70% |
| SVM | 91.4% | 0.72 | 0.69 | 64% |
| MLP | 87.7% | 0.56 | 0.63 | 46% |

Best model selected by **F2 score** — recall is weighted 4x more than precision because missing a churner is costlier than a false alarm. SHAP explanations visualize feature importance across all three models.

## Quick Start

### Prerequisites

- Python 3.12+
- [uv](https://docs.astral.sh/uv/) (recommended) or pip
- An [Anthropic API key](https://console.anthropic.com/) (for AI features)

### Setup

```bash
git clone https://github.com/JstnClmnt/UST-DSA-Python-Workshop.git
cd UST-DSA-Python-Workshop

# Create virtual environment and install dependencies
uv venv
uv pip install -r requirements.txt

# Configure your API key
cp .env.example .env
# Edit .env and add your ANTHROPIC_API_KEY
```

### Run the App

```bash
streamlit run app.py
```

The app opens at `http://localhost:8501`. Select a customer from the dropdown to see their churn risk and AI recommendation.

### Run the Notebook

```bash
jupyter notebook notebooks/01_churn_model.ipynb
```

The pre-trained model is already included. The notebook can be run end-to-end to reproduce it, but training takes ~5 minutes due to GridSearchCV.
